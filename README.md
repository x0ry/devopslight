This is just one .html file. Save it anywhere. Double-click it. It works.

It's built like the description field on an Azure DevOps work item.

Yours, permanently, because it's a file, not a service.

## What it does

- One file. No install.
- Nothing leaves your machine, saved in the browser, not the cloud.
- Real Ctrl+Z. Every edit, undo-able, always.
- Paste an image, it's embedded for real. Shown as a placeholder so it doesn't bury your text.

Copy the file, rename it, it opens blank. Every copy is its own document, tied to its own path. Five tasks, five files. No workspace, no project settings, no config folder, the filesystem is the database!

## Get started

```
1. Save devopslight.html anywhere.
2. Double-click it.
3. Start typing.
```

## Why

A wiki wants a server. A note app wants a subscription. A tracker wants your whole team's calendar. Sometimes you just need to write "Blockers: none" before standup.

This is what's left after you cut all of that away: a textarea, a save button, a file that's actually yours. No framework, no build step.
