A markdown editor. One HTML file. Zero dependencies. Never phones home.

Open it. Type. Ctrl+S. That's the whole product.

---

Every note app wants your email, a subscription, and a server that can shut down in five years. This is one `.html` file. No install, no server, no account. Double-click it.

It's built like the description field on an Azure DevOps work item — title, body, save button, nothing else fighting for your attention. Pulled out of the platform, dropped on your desktop. Yours, permanently, because it's a file, not a service.

## What it does

- One file. No install.
- Nothing leaves your machine, saved in the browser, not the cloud.
- Real Ctrl+Z. Every edit, undo-able, always.
- Paste an image, it's embedded for real. Shown as a placeholder so it doesn't bury your text.
- Two blank lines means two blank lines. Whitespace does what you typed.
- Live preview beside the source. Click the checkboxes right there.
- No autosave, no silent overwrite. Unsaved changes stop you at the door.
- Export to a real `.md` file the moment you want one.

Copy the file, rename it, it opens blank. Every copy is its own document, tied to its own path. Five tasks, five files. No workspace, no project settings, no config folder — the filesystem is the database.

## Get started

```
1. Save devopslight.html anywhere.
2. Double-click it.
3. Start typing.
```

## Why

A wiki wants a server. A note app wants a subscription. A tracker wants your whole team's calendar. Sometimes you just need to write "Blockers: none" before standup.

This is what's left after you cut all of that away: a textarea, a save button, a file that's actually yours. No framework, no build step — one file, readable start to finish.
